# ScreenInk Shortcuts Reference

ScreenInk is built for high-speed live presentations, coding demos, and lectures. You can control every tool without lifting your hands from the keyboard.

## Mode Toggles
- **`F1`** or **`Ctrl + Shift + D`**: Switch between **Sketch Mode** (draw freely over the screen) and **Interact Mode** (mouse clicks pass through to background apps while drawings stay visible).

## Tool Selection
- **`P`**: Freehand Pen (Anti-aliased drawing)
- **`H`**: Highlighter (Semi-transparent stroke behind text)
- **`T`**: Text Tool (Click anywhere to type inline notes)
- **`E`**: Swept-Capsule Eraser (Splits and erases strokes accurately)
- **`X`**: Laser Pointer (Vanishing cursor trail for highlighting)
- **`S`**: Spotlight (Dims the entire screen except for a focused circular highlight)

## Geometric Shapes
- **`R`**: Rectangle / Box
- **`O`**: Circle / Oval / Ellipse
- **`L`**: Straight Line
- **`A`**: Single & Double Arrow
- *Hold or right-click the Shape button on the toolbar to choose from all 19 shapes (Stars, Hearts, Speech Bubbles, Number Callouts, etc.)*.

## Canvas & Color Controls
- **`C`** / **`Shift + C`**: Cycle through the 8 curated color presets without losing custom alpha opacity.
- **`W`**: Cycle Whiteboard canvas modes:
  1. **Transparent**: Live desktop
  2. **White Canvas**: `#FFFFFF`
  3. **Dark Canvas**: `#121212`
  4. **Dot Grid**: `#1E222B` with 28px dot matrix
- **`F`**: Freeze Screen (freezes desktop snapshot so you can annotate static scenes).

## History & Clipboard
- **`Ctrl + Z`**: Undo last stroke (Scoped independently per monitor).
- **`Ctrl + Y`** or **`Ctrl + Shift + Z`**: Redo stroke.
- **`Ctrl + S`**: Export PNG snapshot with full HiDPI crispness.
- **`Ctrl + C`**: Copy high-res annotation directly to the system clipboard.
- **`Delete`** or **`Ctrl + Shift + X`**: Clear all annotations on active screen.
